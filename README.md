# 🏏 IPL Dashboard - Power BI

An interactive Power BI dashboard analyzing Indian Premier League (IPL) data. This dashboard provides deep insights into team performance, player statistics, match analysis, and more, enabling users to explore the dynamics of the IPL over the years.

---

## 🛠️ How to Use

1. Clone or download this repository.
2. Open the `.pbix` file using [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Interact with the visualizations using slicers and filters.
4. Explore and modify the dataset as needed.

---

## 📦 Requirements

- Power BI Desktop (latest version recommended)
- IPL dataset (embedded within the PBIX file)
